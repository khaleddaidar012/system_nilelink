# Task 08: Professional Customer Statement PDF Generator

## Objective
Build a dedicated, presentation-ready Customer Statement PDF generator (`lib/services/statement-pdf-generator.ts`) and associated download/preview endpoint (`GET /api/admin/customers/[id]/statement/pdf`). The generated document must embody Nile Link Logistics' corporate branding, displaying customer details, statement date period, opening balance, chronological transaction table, total debits/credits, closing balance, and running ledger lines.

## Existing System Analysis
1. [`lib/services/invoice-pdf-generator.ts`](file:///d:/khaled/nile_link_website-main/lib/services/invoice-pdf-generator.ts):
   - Proven implementation using `pdfkit` and `naqqash` text shaping.
   - Font loading logic (`Amiri-Regular.ttf`, `Amiri-Bold.ttf`, `Arial.ttf`).
   - Company branding assets (`public/images/logo.png`, Nile Link navy/blue corporate colors `#0f172a`, `#2563eb`).
2. Statement Requirements from User:
   - Must contain:
     - Nile Link Logistics corporate header & contact info.
     - Customer legal name, tax/CR numbers, contact info.
     - Statement period: `From Date -> To Date`.
     - Opening Balance card.
     - Multi-column ledger table:
       | Date | Description | Reference | Debit | Credit | Balance |
     - Summary totals: Total Debit, Total Credit, Closing Balance.
     - Generation date, currency, page numbering.
   - Professional layout suitable for official distribution to corporate clients.

## Requirements
1. **Implement `generateCustomerStatementPdfBuffer`**:
   Create [`lib/services/statement-pdf-generator.ts`](file:///d:/khaled/nile_link_website-main/lib/services/statement-pdf-generator.ts):
   ```typescript
   export async function generateCustomerStatementPdfBuffer(statement: ICustomerStatement): Promise<Buffer>
   ```
2. **Layout Structure (A4 Portrait)**:
   - **Header Section**:
     - Nile Link Logistics corporate logo (`public/images/logo.png`).
     - Company legal info (Nile Link Logistics S.A.E, Damietta/Cairo, Tax ID, Phone, Email).
     - Document Title: `كشف حساب عميل` / `CUSTOMER ACCOUNT STATEMENT`.
     - Metadata Block: Statement Date, Statement Period (`From [Date] To [Date]`), Generated By.
   - **Customer Identification Box**:
     - Customer Company Name.
     - Commercial Register & Tax Card numbers.
     - Address, Email, Phone.
   - **Financial Summary Cards (Executive KPI Box)**:
     - 4-column metric ribbon:
       1. **الرصيد الافتتاحي (Opening Balance)**
       2. **إجمالي الفواتير / المدين (Total Charges / Debit)**
       3. **إجمالي المدفوعات / الدائن (Total Payments / Credit)**
       4. **الرصيد الختامي المستحق (Closing Balance Due)**
   - **Chronological Ledger Table**:
     - Repeating table header across multi-page statements.
     - Columns:
       - **التاريخ (Date)**: Format `YYYY-MM-DD`.
       - **البيان (Description)**: e.g. `فاتورة خدمات لوجستية`, `سداد بنكي`.
       - **المرجع (Reference)**: Invoice Number, Shipment Tracking, or Payment Ref.
       - **مدين (Debit)**: Red/Slate text if > 0.
       - **دائن (Credit)**: Emerald text if > 0.
       - **الرصيد (Balance)**: Running balance formatted with thousands separator and currency.
     - Alternating row backgrounds (`#f8fafc` / `#ffffff`) for high scannability.
   - **Closing Summary & Settlement Instructions**:
     - Net balance highlighted in bold corporate banner.
     - Official payment remittance instructions (Bank CIB details, IBAN, Swift).
     - Official disclaimer & footer with dynamic page numbering: `صفحة {X} من {Y}` (`Page X of Y`).

3. **Backend PDF Endpoint**:
   - Create route [`app/api/admin/customers/[id]/statement/pdf/route.ts`](file:///d:/khaled/nile_link_website-main/app/api/admin/customers/%5Bid%5D/statement/pdf/route.ts):
   - **Method**: `GET`
   - Accepts query params: `fromDate`, `toDate`, `type`, `currency`.
   - Authorizes via `assertStaffPermission(req, "exportCustomerStatements")` (or `viewCustomerStatements`).
   - Calls `generateCustomerLedger(options)` to fetch fresh data.
   - Passes statement data into `generateCustomerStatementPdfBuffer(statement)`.
   - Returns response with headers:
     - `Content-Type: application/pdf`
     - `Content-Disposition: inline; filename="Statement-${customerName}-${fromDate}-${toDate}.pdf"`

## Edge Cases
- **Long Transaction Histories (Multi-page statements)**:
  - If a customer has 50+ transactions in the period, the table must cleanly break across pages, automatically re-rendering the table header without overlapping text or orphan rows.
- **Special Characters in Arabic Descriptions**:
  - Descriptions shaped contextually via `naqqash` to prevent detached Arabic letters.
