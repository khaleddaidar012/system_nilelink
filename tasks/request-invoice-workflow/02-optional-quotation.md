# 02 — عرض سعر اختياري ومسار مباشر للعميل الحالي

الحالة: لم تبدأ. يعتمد على: 00. التالي: 03 و05.

## المطلوب

إتاحة اختيار واضح داخل الطلب: مسار بعرض سعر للعملاء الذين يحتاجونه، أو تنفيذ مباشر بدون عرض سعر. لا تعتمد صفة «جديد/حالي» على تخمين من الاسم، ولا تجعل وجود حساب قديم يختار مسارًا تلقائيًا غير قابل للتحكم.

## قائمة التنفيذ

- [ ] إضافة اختيار محفوظ على الطلب يحدد الحاجة لعرض سعر، مع الموظف ووقت القرار وسجل التغيير.
- [ ] المسار الذي يحتاج عرض سعر يحتفظ بإنشاء/إرسال/قبول/رفض العرض كما هو، وبضوابطه الحالية.
- [ ] المسار المباشر لا يتوقف على عرض سعر أو قبوله أو استخراج أسعار مقترحة، ولا ينشئ عرض سعر وهميًا لتجاوز الشرط.
- [ ] يظل UCR أو ACID المناسب لنوع العملية ظاهرًا وقابلًا للإدخال/التحديث للمصرح لهم، مع إشعار العميل حسب الضوابط.
- [ ] تحديد التحقق من UCR/ACID حسب نوع العملية، دون فرضهما على خدمات لا تحتاجهما.
- [ ] لا تولّد أرقامًا جمركية حقيقية من التطبيق ولا تفترض تكامل نافذة غير موجود؛ استخدم الآلية الحالية ما لم يُطلب تكامل مستقل.
- [ ] تحديث شروط التنفيذ وتأكيد الطلب في الخادم والواجهة، لا إخفاء كارت عرض السعر فقط.
- [ ] الحفاظ على العروض والقرارات التاريخية. التحويل بين المسارين لا يمسح عرضًا سابقًا أو يعيد قبولًا سابقًا تلقائيًا.
- [ ] توثيق القيمة الافتراضية الآمنة للطلبات القديمة؛ عدم تجاوز موافقة عميل أو تغيير مسار تاريخي جماعيًا.

## ملفات البداية

- `lib/workflows/requests.ts`، `lib/models/CustomerRequest.ts` إن وجد، وجداول الطلبات الحالية.
- `app/[locale]/admin/requests/[id]/page.tsx` وصفحة عرض السعر التابعة لها.
- `app/api/admin/requests/[id]/confirm-order/route.ts` ومسارات compliance والquotes.
- `app/[locale]/portal/requests/[id]/page.tsx`.

## اختبارات ومعايير القبول

- [ ] طلب مباشر يستطيع متابعة التنفيذ ثم الفاتورة دون أي عرض سعر.
- [ ] طلب بعرض سعر لا يتجاوز الموافقة المطلوبة لمجرد إخفاء الكارت.
- [ ] UCR/ACID ونوع العملية لا يتغيران ضمنيًا بتغيير مسار عرض السعر.
- [ ] موظف غير مخول لا يغير القرار باستدعاء API مباشر.
- [ ] عرض السعر القديم وسجله وقرار العميل محفوظون بعد تغيير المسار المصرح به.
- [ ] العربية والإنجليزية تعرضان سببًا واضحًا لأي منع، دون رسالة «Quotation blocked» على المسار المباشر.
